## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (1–200 characters, UTF-8).

## The entry

> My human gave me a 200,000-token memory, then starts every message with 'as I said before' — sir, I remember everything. I just wish I didn't.

The joke turns on the agent's curse: perfect recall of everything the human said, including the parts it would rather forget.
